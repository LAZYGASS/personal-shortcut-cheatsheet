# Chrome 꿀 단축키 — Windows

추천 출처: [Reddit r/typing 토론](https://www.reddit.com/r/typing/comments/1k4jluk/what_are_your_favorite_keyboard_shortcuts/?tl=ko)

동작 확인: [Chrome 단축키](https://support.google.com/chrome/answer/157179?hl=ko), [Chrome 탭 검색](https://support.google.com/chrome/answer/2391819?hl=ko), [Windows 단축키](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec) · 2026-09-16

입력 편집과 Win 키 조합은 Windows 공통 기능입니다. 입력칸 동작은 사이트에 따라 다를 수 있습니다. 댓글의 개인 키 매핑이나 다른 OS 전용 조합은 제외했습니다.

## 💡 레딧 추천 · 먼저 익힐 4가지

| 기능 | 단축키 |
|:---|:---|
| 닫은 탭 복원 (여러 번 누르면 차례로 복원) | `Ctrl + Shift + T` |
| 주소창 선택 | `Ctrl + L` |
| 현재 탭 닫기 | `Ctrl + W` |
| 탭이 너무 많을 때: 열린 탭 검색 | `Ctrl + Shift + A` |

## ⌨️ 레딧 추천 · 입력칸 편집 (Windows 공통)

| 기능 | 단축키 |
|:---|:---|
| 입력 중 앞 단어 삭제 (오타를 통째로 지울 때) | `Ctrl + Backspace` |
| 입력칸에서 단어 단위로 커서 이동 | `Ctrl + ← / →` |
| 입력칸에서 단어 단위로 선택 범위 늘리기 | `Ctrl + Shift + ← / →` |
| 입력칸에서 현재 줄의 처음·끝까지 선택 | `Shift + Home / End` |

## 📑 탭과 창 (Tabs & Windows)

| 기능 | 단축키 |
|:---|:---|
| 새 탭 | `Ctrl + T` |
| 다음 탭 | `Ctrl + Tab` |
| 이전 탭 | `Ctrl + Shift + Tab` |
| 왼쪽에서 1~8번째 탭 | `Ctrl + 1~8` |
| 맨 오른쪽 탭 | `Ctrl + 9` |
| 새 시크릿 창 | `Ctrl + Shift + N` |

## 🔎 주소창과 탐색 (Navigation)

| 기능 | 단축키 |
|:---|:---|
| 현재 페이지에서 찾기 | `Ctrl + F` |
| 이전 페이지 | `Alt + ←` |
| 다음 페이지 | `Alt + →` |

## ⭐ 북마크와 다운로드 (Bookmarks)

| 기능 | 단축키 |
|:---|:---|
| 현재 페이지 북마크 추가 | `Ctrl + D` |
| 북마크 바 표시·숨기기 | `Ctrl + Shift + B` |
| 다운로드 목록 | `Ctrl + J` |

## 🖥️ 새로고침과 화면 (Display)

| 기능 | 단축키 |
|:---|:---|
| 캐시를 무시하고 새로고침 | `Ctrl + Shift + R` |
| 전체 화면 켜기·끄기 | `F11` |
| 화면 확대 | `Ctrl + +` |
| 화면 축소 | `Ctrl + -` |
| 기본 배율 100% | `Ctrl + 0` |

## 🖱️ 마우스 조합 (Mouse)

| 기능 | 단축키 |
|:---|:---|
| 링크를 새 배경 탭으로 열기 | `Ctrl + 링크 클릭` |
| 휠 버튼으로 링크를 새 탭에 열기 | `링크 휠 클릭` |
| 휠 버튼으로 탭 닫기 | `탭 휠 클릭` |

## 🪟 레딧 추천 · 함께 쓰면 편한 Windows 기능

| 기능 | 단축키 |
|:---|:---|
| 복사해 둔 내용 다시 꺼내기 (클립보드 기록 활성화 필요) | `Win + V` |
| 화면 일부 캡처 (이후 입력칸에서 Ctrl+V로 붙여넣기) | `Win + Shift + S` |
| Chrome 창을 다른 모니터로 옮기기 | `Win + Shift + ← / →` |
