# XG5000 Shortcuts (LS ELECTRIC PLC)

> XG5000 **기본(Default) 단축키** 기준입니다. XG5000의 **[도구] → [단축키]** 메뉴에서 사용자화할 수 있습니다.
> 심볼 입력키는 XG5000 LD(래더) 편집 매뉴얼 기준입니다.

## PLC 플래그와 스텝 메모

키보드 단축키가 아니라 PLC 프로그램에서 사용하는 디바이스 주소입니다. 아래 플래그 표기는 XGB 계열 자료 기준이며, 실제 CPU·언어의 플래그 일람으로 주소와 지원 여부를 확인합니다.

| 검색어 / 주소 | 의미 | 기억할 점 |
|:---|:---|:---|
| F99 ON / `F0099` / `_ON` | 항상 ON인 플래그 | PLC RUN 중 매 스캔 참인 조건에 사용 |
| `F009B` / `_1ON` | 첫 1스캔만 ON인 플래그 | RUN 시작 시 초기값 설정 등 한 번 처리할 로직에 사용 |
| `S000.00` | 스텝 컨트롤러의 000번 그룹, 00번 스텝 | 현재 순서 제어 단계가 활성인지 나타내는 주소 |

### F009B: “프로그램이 시작하면 한 번”의 뜻

PLC는 프로그램을 반복 처리하며, 한 차례 처리하는 주기를 **스캔**이라고 합니다. `F009B`는 RUN을 시작한 첫 스캔에만 ON입니다. XG5000 편집기를 여는 순간을 뜻하지 않습니다. STOP → RUN으로 다시 시작하면 첫 스캔도 다시 발생하므로, 장비 수명 전체에서 딱 한 번이라는 뜻은 아닙니다.

`F0099`는 계속 참인 조건, `F009B`는 시작할 때만 참인 조건으로 기억하면 됩니다. 다른 접점과 함께 사용한 회로는 그 접점 조건까지 충족해야 실행됩니다.

### S000.00: 지금 어느 단계인지 기억하는 주소

`S`는 스텝 컨트롤러(스텝 릴레이), `000`은 그룹, `.00`은 그 그룹의 0번 스텝입니다. 소수나 초 단위 시간 값이 아닙니다. 해당 스텝이 ON이면 그 주소의 접점 조건은 참입니다.

설명용으로 `S000.00 = 대기`, `S000.01 = 운전`, `S000.02 = 완료`라고 정할 수 있습니다. **대기·운전·완료라는 의미는 작성자가 부여하는 것이며 주소 자체의 고정 의미가 아닙니다.** 자동으로 다음 단계로 넘어가는 것도 아니므로 전환 조건과 스텝 설정 로직이 필요합니다.

`F009B`로 시작 첫 스캔을 감지하여 `S000.00`을 초기 스텝으로 설정하는 방식으로 조합할 수 있습니다. 이는 개념 설명이며 사용자 프로그램에서 확인한 회로는 아닙니다. 실제 초기화 명령과 유지 설정은 해당 CPU와 프로젝트에서 확인합니다.

### 확인 범위와 출처

- **공식 확인:** `F0099 / _ON`, `F009B / _1ON`의 정의 — [LS ELECTRIC XBL-CMEA/T2 V1.6 (2024-06), 부록 A-4](https://ssq.ls-electric.com/uploads/document/17183268442520/XBL-CMEA_T2_Manual_V1.6_202406_KR.pdf).
- **공식 확인:** S 영역이 스텝 컨트롤러이고 XGB H형 자료에서 `S000.00~S127.99`로 표시됨 — [XGB Hardware English Manual V1.7, §5.5.2, 5-33](https://www.ls-electric.com/upload/customer/download/61fb48f7-b041-4b35-a2ce-3ba60371c47c/XGB%20Hardware%20English%20ManualV1.7.pdf).
- **공식 예제:** `S000.00`을 초기 스텝, `S000.01`을 P1 도착으로 사용 — [XBC UP Positioning Tutorial V1.2, §4.4.2, 26/28](https://sol.ls-electric.com/uploads/document/16408293242570/XBC_UP_Positioning_Tutorial_V1.2.pdf).
- **미확인:** 사용자의 CPU 모델, 실제 `S000.00`의 역할, `F009B`와 연결된 회로. `F99 ON`은 사용자가 기억한 검색어로 보존하고 공식 주소 `F0099`를 함께 표시합니다. CPU에 따라 `F00099`처럼 표기 자릿수가 달라질 수 있으므로 다른 기종에 그대로 복사하지 않습니다.
