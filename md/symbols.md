# 자주 쓰는 특수문자

자주 찾는 45개만 모은 목록입니다. 화면에서 기호 버튼을 누르면 기호만 복사됩니다.

| 기호 | 이름 | 사용 예·구분 |

⌀는 지름 기호(U+2300), Ø는 라틴 문자, Φ는 그리스 대문자 피(phi), π는 원주율 표기입니다. 서로 다른 문자이므로 문서의 목적에 맞게 선택합니다.

## SI 표기 규칙 빠른 참조

특수문자 화면에서 **SI 규칙만 보기**를 누르거나 `SI`, `kW`, `띄어쓰기`를 검색하세요.

### SI · 대소문자와 접두어

- **킬로와트는 kW**: k는 kilo(10³), W는 watt. 5 kW로 씁니다. KW·kw·Kw는 피하세요.
- **접두어는 단위에 붙이기**: kW, mm, MPa처럼 붙입니다. k W, m m처럼 나누지 않습니다.
- **m과 M은 다릅니다**: m = 10⁻³, µ = 10⁻⁶, k = 10³, M = 10⁶, G = 10⁹. mW와 MW는 10⁹배 차이입니다.
- **단위 기호의 대소문자 유지**: m, s, kg는 소문자. W, V, A, Pa, Hz는 정해진 대소문자를 그대로 씁니다.

### SI · 띄어쓰기와 온도

- **숫자와 단위 사이 한 칸**: 5 kW, 220 V, 25 °C, 50 %처럼 숫자와 기호 사이를 띕니다.
- **각도의 °는 예외**: 각도는 90°처럼 붙입니다. 섭씨는 25 °C처럼 숫자 뒤를 띄우되 °와 C는 붙입니다.
- **켈빈은 K, °K가 아닙니다**: 300 K로 씁니다. 온도 차이 1 K는 1 °C와 크기가 같지만, 0 °C = 273.15 K입니다.

### SI · 제곱과 복합 단위

- **제곱·세제곱은 접두어까지 적용**: 1 cm² = 10⁻⁴ m², 1 cm³ = 10⁻⁶ m³. cm²는 (cm)²입니다.
- **단위의 곱은 공백 또는 가운데 점**: N m 또는 N·m로 씁니다. ms는 밀리초이고, m s는 미터와 초의 곱입니다.
- **나눗셈의 분모는 분명하게**: m/s, m³/h처럼 씁니다. W/m/K 대신 W/(m·K) 또는 W m⁻¹ K⁻¹로 씁니다.
- **기호에 복수형·약어 마침표를 붙이지 않기**: 5 kg, 10 s, 2 cm³로 씁니다. 5 kgs, 10 sec, 2 cc는 피합니다. 문장 끝 마침표는 별개입니다.
- **리터·분·시간은 SI와 함께 사용 가능**: L(또는 l), min, h는 SI 자체의 단위는 아니지만 SI와 함께 쓰도록 허용됩니다. 20 L/min처럼 표기합니다.

출처: [BIPM SI Brochure 제9판 V4.01, 2026-06](https://www.bipm.org/documents/20126/41483022/SI-Brochure-9-EN.pdf), §2.3.1(온도), §3(접두어), §4(비SI 단위), §5.2(기호), §5.4.3·5.4.7(띄어쓰기·퍼센트). 한국어 설명과 예시는 해당 규칙을 바탕으로 정리했습니다.

## 빠른 문자 입력 (Windows)

Num Lock을 켜고 Alt를 누른 채 **숫자패드**로 코드를 입력한 다음 Alt를 놓습니다. 위쪽 숫자열은 사용할 수 없습니다. 아래 Alt 코드는 서유럽 Windows 코드페이지 기준이며 Windows 언어·앱에 따라 다를 수 있습니다.

| 문자 | 입력 코드 |
|:---|:---|
| ° | Alt+0176 |
| ² | Alt+0178 |
| ³ | Alt+0179 |
| ± | Alt+0177 |
| Ø | Alt+0216 |
| ø | Alt+0248 |
| µ | Alt+0181 |

Word에서는 `U+2082` 입력 후 `Alt+X` → ₂, `U+2083` → ₃, `U+2300` → ⌀입니다. Word 등 지원 앱 전용으로 Excel·PowerPoint 전체에 적용되는 방법은 아닙니다.

앱 공통 첨자 서식 단축키는 없습니다. 문자 자체를 복사하여 `Win+V`에서 고정하면 지원 앱에서 다시 붙여넣을 수 있습니다.

출처: [Microsoft 도 기호](https://support.microsoft.com/en-us/word/insert-degree-symbol), [문자 코드 입력](https://support.microsoft.com/en-gb/word/insert-ascii-or-unicode-latin-based-symbols-and-characters), [클립보드 기록](https://support.microsoft.com/en-au/windows/using-the-clipboard-30375039-ce71-9fe4-5b30-21b7aab6b13f). Alt 숫자 값은 해당 코드페이지에서의 문자 값이며, 실제 사용자 앱에서의 키 입력은 별도 확인이 필요합니다.

`Alt+248`은 앞의 0 유무와 프로그램·문자표에 따라 결과가 달라집니다. 지름 전용 기호는 ⌀이며 Ø·ø는 별도의 라틴 문자입니다. 사용자가 말한 Alt+248의 실제 앱 결과는 미확인입니다. AutoCAD에서 지름을 입력하려면 `%%c`를 사용합니다. [Autodesk 공식 안내](https://www.autodesk.com/blogs/autocad/adding-diameter-symbol-autocad-drawings/).

## 분수 문자 · 슬래시 대용

| 문자 | 뜻 | Windows Alt 코드 (서유럽 코드페이지 기준) |
|:---|:---|:---|
| ½ | 1/2 | Alt+0189 |
| ¼ | 1/4 | Alt+0188 |
| ¾ | 3/4 | Alt+0190 |
| ⅓ | 1/3 | Word U+2153 → Alt+X |
| ⅔ | 2/3 | Word U+2154 → Alt+X |
| ⁄ | 분수용 빗금 U+2044 | Word U+2044 → Alt+X |

`1⁄2`는 숫자와 분수용 빗금을 조합한 세 글자이고 `½`는 한 글자입니다. 숫자 전용 입력칸에서는 둘 다 거부될 수 있습니다. 이 경우 허용 형식을 확인하고 정확히 표현 가능한 값은 `0.5`처럼 소수로 입력합니다. `⅓`은 유한 소수로 정확히 표현되지 않으므로 필요한 정밀도도 확인합니다.

출처: [Unicode Number Forms](https://www.unicode.org/charts/nameslist/n_2150.html), [General Punctuation U+2044](https://www.unicode.org/charts/nameslist/n_2000.html), 위 Microsoft 문자 코드 안내.
