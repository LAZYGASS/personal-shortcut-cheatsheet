# 자주 쓰는 특수문자

자주 쓰는 문자를 입력 방법별로 모은 목록입니다. 화면에서 기호 버튼을 누르면 기호만 복사됩니다.

## 입력 방법별 빠른 목록

- **ㄹ + 한자 · 단위**: ℃ ℉ ㎜ ㎝ ㎞ ㎡ ㎥ ㎖ ℓ ㎎ ㎏ ㎾ ㎿ ㎫
- **ㅊ + 한자 · 분수 · 위첨자 · 아래첨자**: ½ ¼ ¾ ⅓ ⅔ ⅛ ⅜ ⅝ ⅞ ¹ ² ³ ⁴ ⁿ ₁ ₂ ₃ ₄
- **ㄲ + 한자 · 지름 대용 문자**: Ø ø
- **ㅎ + 한자 · 그리스 문자**: Φ π Ω
- **ㄷ + 한자 · 계산 · 비교**: ± × ÷ ≠ ≤ ≥
- **ㅁ + 한자 · 표시 · 화살표**: ※ ○ ● □ ■ ☆ ★ → ← ↑ ↓ ↔
- **ㄱ + 한자 · 문장 부호**: · … ／
- **직접 입력 · 일반 단위**: °C °F m² m³ mm² µm m³/h L/min MPa kW V
- **클릭해서 복사 · 체크 · 지름 · 기타**: ⌀ ° ≈ ✓ ☑ ☐ • ⁄

ㄹ+한자 후보의 ㎾·㎡·℃ 등은 한 글자 호환 문자입니다. 일반 문자 조합 kW·m²·°C와 구분합니다.

자음별 분류는 [libhangul MS 호환 문자표](https://github.com/libhangul/libhangul/blob/main/data/hanja/mssymbol.txt)와 대조했습니다. 실제 Windows 입력기·버전별 후보 차이가 있을 수 있습니다.

## 지름 · 파이 · 도면

| 기호 | 이름 | 사용 예·구분 |
|:---|:---|:---|
| ⌀ | 지름 기호 | ⌀25 · 지름을 뜻하는 전용 기호 |
| Ø | 빗금 O · 지름 대용 표기 | Ø25 · 라틴 문자이므로 도면 지정 기호 확인 |
| Φ | 대문자 그리스 피 (phi) | 그리스 문자 · 지름 기호 ⌀와 구분 |
| π | 원주율 파이 | π ≈ 3.14159 |
| ° | 도 · 각도 | 90° |
| ± | 플러스마이너스 · 공차 | 25 ± 0.1 |

## 온도 · 면적 · 부피

| 기호 | 이름 | 사용 예·구분 |
|:---|:---|:---|
| °C | 섭씨 | 25 °C |
| °F | 화씨 | 77 °F |
| m² | 제곱미터 | 10 m² |
| m³ | 세제곱미터 | 2 m³ |
| mm² | 제곱밀리미터 | 2.5 mm² |
| µm | 마이크로미터 | 10 µm |

| 기호 | 이름 | 사용 예·구분 |
|:---|:---|:---|
| m³/h | 시간당 세제곱미터 | 100 m³/h |
| L/min | 분당 리터 | 20 L/min |

## 계산 · 비교

| 기호 | 이름 | 사용 예·구분 |
|:---|:---|:---|
| × | 곱하기 | 가로 × 세로 |
| ÷ | 나누기 | 10 ÷ 2 |

| ≠ | 같지 않음 | a ≠ b |
| ≈ | 거의 같음 | π ≈ 3.14 |

## 체크 · 문서 표시

| 기호 | 이름 | 사용 예·구분 |
|:---|:---|:---|
| ✓ | 체크 표시 | 완료한 항목 |
| ☑ | 체크된 네모 | 선택한 항목 |
| ☐ | 빈 체크박스 | 확인할 항목 |
| ※ | 참고 표시 | 추가 설명 앞에 |
| • | 글머리표 | 목록 항목 앞에 |
| · | 가운뎃점 | 설계·제작·설치 |

## 방향 · 위아래 첨자

| 기호 | 이름 | 사용 예·구분 |
|:---|:---|:---|
| → | 오른쪽 화살표 | 입력 → 출력 |
| ← | 왼쪽 화살표 | 되돌아가는 방향 |
| ↑ | 위쪽 화살표 | 온도 상승 |
| ↓ | 아래쪽 화살표 | 온도 하강 |
| ² | 위첨자 2 | x² |
| ₃ | 아래첨자 3 | NH₃ |

⌀는 지름 기호(U+2300), Ø는 라틴 문자, Φ는 그리스 대문자 피(phi), π는 원주율 표기입니다. 서로 다른 문자이므로 문서의 목적에 맞게 선택합니다.

출처: [Unicode Miscellaneous Technical](https://www.unicode.org/charts/nameslist/n_2300.html).

SI 규칙은 [별도 문서](si_rules.md)와 **SI 규칙 메뉴**에서 확인합니다.

## 빠른 문자 입력 (Windows)

Num Lock을 켜고 Alt를 누른 채 **숫자패드**로 코드를 입력한 다음 Alt를 놓습니다. 위쪽 숫자열은 사용할 수 없습니다. 아래 Alt 코드는 서유럽 Windows 코드페이지 기준이며 Windows 언어·앱에 따라 다를 수 있습니다.

| 문자 | 입력 코드 |
|:---|:---|
| ° | Alt+0176 |
| ² | Alt+0178 |
| ³ | Alt+0179 |
| ± | Alt+0177 |
| Ø | Alt+0216 |
| ø | Alt+0248 |
| µ | Alt+0181 |

Word에서는 `U+2082` 입력 후 `Alt+X` → ₂, `U+2083` → ₃, `U+2300` → ⌀입니다. Word 등 지원 앱 전용으로 Excel·PowerPoint 전체에 적용되는 방법은 아닙니다.

앱 공통 첨자 서식 단축키는 없습니다. 문자 자체를 복사하여 `Win+V`에서 고정하면 지원 앱에서 다시 붙여넣을 수 있습니다.

출처: [Microsoft 도 기호](https://support.microsoft.com/en-us/word/insert-degree-symbol), [문자 코드 입력](https://support.microsoft.com/en-gb/word/insert-ascii-or-unicode-latin-based-symbols-and-characters), [클립보드 기록](https://support.microsoft.com/en-au/windows/using-the-clipboard-30375039-ce71-9fe4-5b30-21b7aab6b13f). Alt 숫자 값은 해당 코드페이지에서의 문자 값이며, 실제 사용자 앱에서의 키 입력은 별도 확인이 필요합니다.

`Alt+248`은 앞의 0 유무와 프로그램·문자표에 따라 결과가 달라집니다. 지름 전용 기호는 ⌀이며 Ø·ø는 별도의 라틴 문자입니다. 사용자가 말한 Alt+248의 실제 앱 결과는 미확인입니다. AutoCAD에서 지름을 입력하려면 `%%c`를 사용합니다. [Autodesk 공식 안내](https://www.autodesk.com/blogs/autocad/adding-diameter-symbol-autocad-drawings/).

## 분수 문자 · 슬래시 대용

| 문자 | 뜻 | Windows Alt 코드 (서유럽 코드페이지 기준) |
|:---|:---|:---|
| ½ | 1/2 | Alt+0189 |
| ¼ | 1/4 | Alt+0188 |
| ¾ | 3/4 | Alt+0190 |
| ⅓ | 1/3 | Word U+2153 → Alt+X |
| ⅔ | 2/3 | Word U+2154 → Alt+X |
| ⁄ | 분수용 빗금 U+2044 | Word U+2044 → Alt+X |

`1⁄2`는 숫자와 분수용 빗금을 조합한 세 글자이고 `½`는 한 글자입니다. 숫자 전용 입력칸에서는 둘 다 거부될 수 있습니다. 이 경우 허용 형식을 확인하고 정확히 표현 가능한 값은 `0.5`처럼 소수로 입력합니다. `⅓`은 유한 소수로 정확히 표현되지 않으므로 필요한 정밀도도 확인합니다.

출처: [Unicode Number Forms](https://www.unicode.org/charts/nameslist/n_2150.html), [General Punctuation U+2044](https://www.unicode.org/charts/nameslist/n_2000.html), 위 Microsoft 문자 코드 안내.

## 프로그램별 입력법

특수문자 안의 **프로그램별 입력법** 탭에서 확인합니다. Windows 기준이며 AutoCAD는 문자 편집 영역에서 입력합니다. Word Alt+X는 다른 앱의 공통 단축키가 아닙니다.

| 문자 | Word | Excel·Google Sheets | AutoCAD |
|:---|:---|:---|:---|
| ⌀ | U+2300 → Alt+X | 기호 복사 → 셀에 붙여넣기 | `%%c (지름 표시)` |
| Ø | U+00D8 → Alt+X | ㄲ → 한자 → Ø | `\U+00D8` |
| ø | U+00F8 → Alt+X | ㄲ → 한자 → ø | `\U+00F8` |
| Φ | U+03A6 → Alt+X | ㅎ → 한자 → Φ | `\U+03A6` |
| π | U+03C0 → Alt+X | ㅎ → 한자 → π | `\U+03C0` |
| Ω | U+03A9 → Alt+X | ㅎ → 한자 → Ω | `\U+03A9` |
| ² | U+00B2 → Alt+X | ㅊ → 한자 → ² | `\U+00B2` |
| ³ | U+00B3 → Alt+X | ㅊ → 한자 → ³ | `\U+00B3` |
| ₂ | U+2082 → Alt+X | ㅊ → 한자 → ₂ | `\U+2082` |
| ₃ | U+2083 → Alt+X | ㅊ → 한자 → ₃ | `\U+2083` |
| ½ | U+00BD → Alt+X | ㅊ → 한자 → ½ | `\U+00BD` |
| ¼ | U+00BC → Alt+X | ㅊ → 한자 → ¼ | `\U+00BC` |
| ¾ | U+00BE → Alt+X | ㅊ → 한자 → ¾ | `\U+00BE` |
| ⅓ | U+2153 → Alt+X | ㅊ → 한자 → ⅓ | `\U+2153` |
| ⅔ | U+2154 → Alt+X | ㅊ → 한자 → ⅔ | `\U+2154` |
| ° | U+00B0 → Alt+X | 기호 복사 또는 Windows Alt+0176 | `%%d` |
| °C | U+00B0 → Alt+X → C | ° 복사 후 C 입력 | `%%dC` |
| ± | U+00B1 → Alt+X | ㄷ → 한자 → ± | `%%p` |
| m² | m 입력 → U+00B2 → Alt+X | m 입력 → ㅊ → 한자 → ² | `m\U+00B2` |
| m³ | m 입력 → U+00B3 → Alt+X | m 입력 → ㅊ → 한자 → ³ | `m\U+00B3` |
| kW | kW 그대로 입력 | kW 그대로 입력 | `kW 그대로 입력` |
| ✓ | U+2713 → Alt+X | 기호 복사 → 셀에 붙여넣기 | `\U+2713 (지원 글꼴 필요)` |

문자 입력과 첨자 서식은 다릅니다. AutoCAD에서는 지원 글꼴을 사용하고 임의 분수는 MTEXT의 스택 기능을 이용합니다.

출처: [Microsoft 문자 코드](https://support.microsoft.com/en-gb/word/insert-ascii-or-unicode-latin-based-symbols-and-characters), [Excel 첨자](https://support.microsoft.com/en-us/excel/format-text-or-numbers-as-superscript-or-subscript), [Autodesk 지름·Unicode](https://www.autodesk.com/blogs/autocad/adding-diameter-symbol-autocad-drawings/).
