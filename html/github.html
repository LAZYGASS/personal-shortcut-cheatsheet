📁 폴더 변경사항 올리기

현재 폴더에서 수정한 내용을 확인한 뒤, 원하는 폴더만 골라 안전하게 원격 저장소에 올립니다.

  1. 1 · 확인 변경 상태 보기 git status
  2. 2 · 선택 폴더 전체 스테이징 git add <folder>/
  3. 3 · 기록 의미 있는 메시지로 커밋 git commit -m "설명"
  4. 4 · 업로드 현재 브랜치 푸시 git push

처음 푸시하는 브랜치라면 git push -u origin <branch>를 사용하세요.
