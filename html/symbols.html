자주 찾는 기호 45개와 SI 표기 규칙 12개를 모았습니다. 기호 버튼을 누르면 기호만 복사됩니다. 별표로 자주 쓰는 것을 모아두세요.

파이 검색: ⌀(지름), Ø·ø(라틴 문자), Φ(피·그리스 문자), π(원주율)를 구분해서 고르세요. 단위는 복사하기 좋은 일반 문자 조합으로 제공합니다.

· BIPM 공식 SI 지침 (§3–5)

빠른 입력: Alt+숫자 · 위첨자/아래첨자

Windows: Num Lock을 켜고 Alt를 누른 채 오른쪽 숫자패드로 코드를 입력한 뒤 Alt를 놓습니다. 위쪽 숫자열은 사용할 수 없습니다. 예: Alt+0176 → °, Alt+0178 → ², Alt+0179 → ³.

Alt 코드는 Windows 언어·코드페이지·앱에 따라 결과가 다를 수 있습니다. 앞의 0 유무도 중요합니다. ø는 서유럽 문자표 기준 Alt+0248이며, Alt+248은 프로그램·문자표에 따라 다르므로 지름이나 도 기호로 일괄 단정하지 않습니다. AutoCAD 지름 입력은 %%c입니다. 모든 프로그램에 공통인 첨자 서식 단축키는 없습니다.

Word: U+2082 입력 → Alt+X = ₂, U+2083 → Alt+X = ₃. 이 방식은 Word 등 지원 앱용이며 Excel·PowerPoint 공통 단축키가 아닙니다.

여러 앱에서 반복 입력: ²·³·₂·₃ 같은 문자를 복사한 뒤 Win+V에서 고정하면 다시 골라 붙여넣을 수 있습니다. 임의의 글자를 첨자로 만드는 서식과는 다릅니다.

공식 안내: 도 기호 · 문자 코드 입력

분수 입력: ½·¼·¾·⅓·⅔는 한 글자입니다. 분수용 빗금 ⁄로 1⁄2처럼 쓸 수도 있습니다. 숫자만 허용하는 입력칸은 이 문자도 거부할 수 있으므로 허용 형식을 확인하세요.

예: 파이 · 체크 · 온도 · 제곱 · 유량 · 전압
